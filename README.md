# masm-learn · 文本驱动版

这是 `masm-learn` 教程的**文本驱动重构版本**，对应原项目的全部 25 章（00~24）。

## 与原目录的关系

- 原目录（`masm-learn/`）保持不变，是最初的代码驱动版本；
- 本目录（`rebuild/`）镜像原项目的章节目录与全部源码（`.asm`、`Makefile`、`common.asm`、数据文件），**源码未做任何修改**；
- 每章的 `README.md` 已重写为"文本驱动"结构：**先讲知识点，再给实践代码，最后讲代码重点**。

## 为什么重构

原版本以"代码逐段讲解"为骨架，读者需要一边读代码一边看注释才能拼出完整理解，属于**代码驱动**。重构后改为**文本驱动**：

1. **知识点讲解**为核心——把概念、原理、规律用文字、表格、示意图讲透，正文只贴最小代码片段；
2. **实践用例**在知识点之后——给出本章完整 `.asm` 的用途、构建命令、真实运行/编译输出、`.lst` 与 objdump 实证，供读者动手体会；
3. **代码重点讲解**在末尾——挑出 3~6 处最值得注意的代码，回扣前面的知识点，解释"为什么这么写"。

这样读者先建立概念框架，再用代码验证，最后通过重点讲解把"学"与"练"对应起来。

## 阅读方式

建议按章节顺序阅读。每章 README 固定包含：

```
1. 本章目标
2. 前置 / 项目结构
3. 知识点讲解         ← 核心，先读完
4. 实践用例           ← 对照知识点读源码并运行
5. 代码重点讲解       ← 回扣知识点
6. 常见坑
7. 练习
8. 下一章预览
```

涉及 ABI 的章节，"知识点讲解"中都会复述 Windows x64 调用约定四件套：`RCX/RDX/R8/R9` 参数传递、32 字节影子空间、16 字节栈对齐、非易失寄存器。

## 构建

每章的 `Makefile` 用法不变，进入对应目录执行 `make` 即可。编译产物（`.obj`、`.exe`）不纳入本目录。
