# nasm-learn · Windows x64 汇编入门

这是一套从机器码、寄存器和内存讲起的 **NASM x64 文本驱动教程**，包含前言与全部 25 章（00~24）。默认读者理解变量、函数、条件、循环以及“源码需要编译”等编译型高级语言常识；**不预设寄存器、机器码、Windows ABI、PE、COM 等机器或平台知识**。这些内容会在首次需要时解释，暂时用不到的细节会标为“拓展”或留到后续章节。

## 教程组织

- 当前项目根目录是 `nasm-learn/`，前言、00～24 章、共享定义和各章源码都在此目录下；
- 本次细化只修改各级 `README.md`，不改动 `.asm`、`Makefile` 或 `common.asm`；
- 每章采用“先讲知识点，再给实践代码，最后讲代码重点”的文本驱动结构。源码中保留的教学简化会在文档里单独标明，并给出通用正确写法。

## 为什么重构

原版本以"代码逐段讲解"为骨架，读者需要一边读代码一边看注释才能拼出完整理解，属于**代码驱动**。重构后改为**文本驱动**：

1. **知识点讲解**为核心——把概念、原理、规律用文字、表格、示意图讲透，正文只贴最小代码片段；
2. **实践用例**在知识点之后——给出本章完整 `.asm` 的用途、构建命令、真实运行/编译输出、`.lst` 与 objdump 实证，供读者动手体会；
3. **代码重点讲解**在末尾——挑出 3~6 处最值得注意的代码，回扣前面的知识点，解释"为什么这么写"。

这样读者先建立概念框架，再用代码验证，最后通过重点讲解把"学"与"练"对应起来。

## 开始之前：按最小路线读前言

先打开 [汇编入门前言](preface/README.md)，按开头的“最小必读路线”准备十六进制、寄存器和工具基础即可进入第 00 章。栈、Windows ABI、PE、DLL 与 GDB 细节都是**按需查阅**，不再是第一个程序之前的集中预习任务。

每章只要求掌握当章实验所需的新内容。遇到“拓展（可跳过）”时，可以先完成主线，再按需回来查。

## 阅读方式

建议先读前言，再按章节顺序阅读。每章 README 固定包含：

```
1. 本章目标
2. 前置 / 项目结构
3. 知识点讲解         ← 核心，先读完
4. 实践用例           ← 对照知识点读源码并运行
5. 代码重点讲解       ← 回扣知识点
6. 常见坑
7. 练习
8. 下一章预览
```

Windows x64 调用约定在第 06 章集中讲解。后续章节只回顾当前调用需要的规则，例如额外的栈参数或浮点参数，不再把整套 ABI 当作新知识重复展开。
